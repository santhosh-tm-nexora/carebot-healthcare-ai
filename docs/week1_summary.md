Reviewed scispaCy, the i2b2/n2c2 clinical NER shared tasks, and an LLM structured-extraction approach for clinical notes. Defined a four-stage architecture: preprocessing (abbreviation normalization), spaCy NER for diagnosis/medication/dosage/follow-up (rule-based baseline, custom model from the labelled samples later), an entity-constrained LLM summary step to limit hallucination, and Pydantic-validated JSON output. Evaluation plan: per-entity precision/recall/F1 on the 30 test notes, JSON validity rate, and a manual faithfulness check on summaries. Set up the repo with README, schema, pipeline skeleton, evaluation module, NER training script, and passing unit tests. No real patient data is used.
